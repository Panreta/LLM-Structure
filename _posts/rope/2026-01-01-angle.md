**Angles.** Put $$m = n$$ in the angle equation and use the boundary condition again:

$$\Theta_f(q, m) - \Theta_f(k, m) = \Theta_g(q, k, 0) = \Theta_f(q, 0) - \Theta_f(k, 0) = \Theta(q) - \Theta(k)$$

where $$\Theta(\cdot)$$ is the original angle. The angle between $$q$$ and $$k$$ does not change when both sit at the same position. Rearranged,

$$\Theta_f(q, m) - \Theta(q) = \Theta_f(k, m) - \Theta(k) =: \varphi(m)$$

The extra angle that position $$m$$ adds is the same for every vector: a function $$\varphi(m)$$ of the position alone.

Now compare neighbouring positions, using the angle equation with $$m - n = 1$$:

$$\varphi(m) - \varphi(m-1) = \bigl[\Theta_f(q, m) - \Theta(q)\bigr] - \bigl[\Theta_f(k, m-1) - \Theta(k)\bigr] = \Theta_g(q, k, 1) + \Theta(k) - \Theta(q) =: \theta$$

The right side does not depend on $$m$$, so $$\varphi$$ grows by the same $$\theta$$ at every step. Since $$\varphi(0) = \Theta_f(q, 0) - \Theta(q) = 0$$, it is an arithmetic sequence:

$$\varphi(m) = m\theta, \qquad \Theta_f(\ast, m) = \Theta(\ast) + m\theta$$

**The figure** shows the steps. Each position turns a vector by one more $$\theta$$ (the dots), and $$q$$ and $$k$$ turn by the same amount, so the angle between them is unchanged.
